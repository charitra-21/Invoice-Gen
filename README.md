# 🧾 Invoice Generator

A full-stack web application to create, manage, and export professional invoices بسهولة and efficiently.

Built using the MERN stack, this project focuses on clean UI, real-time calculations, and seamless user experience.

---

## 🌟 Features

- 🧾 Create professional invoices with client details
- ➕ Add multiple items dynamically
- 💰 Automatic calculation of subtotal, tax, and total
- 📄 Export invoices as PDF
- 🗂️ Store and manage invoices
- 🔐 User authentication (Login/Signup)
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5, CSS3
- Vite

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other Tools
- JWT Authentication
- jsPDF / html2canvas (for PDF generation)
- REST API
